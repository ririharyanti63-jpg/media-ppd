# Petualangan Tumbuh

Game belajar 3D untuk anak sekolah dasar. Game dijalankan sebagai situs lokal agar modul 3D dapat dimuat dengan benar.

## Menjalankan game di Windows

1. Pastikan Python sudah terpasang.
2. Klik dua kali `start-game.bat` di folder proyek.

Atau jalankan dari Command Prompt:

```cmd
start-game.bat
```

Server lokal akan berjalan dan game terbuka di browser pada <http://127.0.0.1:8765/>.

## Kontrol

- **W A S D** untuk bergerak.
- **Mouse** untuk mengubah arah pandang.
- Tekan **E** atau tombol belajar di dekat pos untuk membuka tantangan.
- Tombol musik di bagian atas dapat digunakan untuk menyalakan atau mematikan musik.

Three.js dan font game dimuat dari CDN, jadi koneksi internet diperlukan.
